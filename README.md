# Mambot 🎵

A Discord bot that plays random UmaMusume sounds in voice channels at random intervals and supports soundboard commands.

## Features

- 🔊 Stays 24/7 in a Discord voice channel
- 🎲 Plays random sounds every 30-60 minutes
- 🎹 Slash command soundboard (`/mambot <sound>`)
- 🔄 Auto-reconnects if disconnected

## Sound Categories

- **Mambo** - 3 sounds
- **Weii** - 1 sound

## Setup

See [Deployment Guide](private-documentations/deployment-guide.md) for complete setup and deployment instructions.

## Commands

- `/mambot mambo` - Play a random mambo sound
- `/mambot weii` - Play the weii sound

## Requirements

- Node.js 18 or higher
- Discord Bot Token
- Discord Server (Guild)
